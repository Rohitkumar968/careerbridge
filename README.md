# 🚀 CareerBridge — AI-Powered Job & Recruitment Platform

🔗 **Live Demo:** https://careerbridgejob-portal.netlify.app/

CareerBridge is a full-stack **AI-powered job and recruitment platform** built using the MERN Stack. It connects job seekers and recruiters through a modern platform where users can search for jobs, apply for positions, manage applications, schedule interviews, and manage recruitment activities.

## 🔐 Authentication & Security

CareerBridge uses **JWT-based authentication** and role-based authorization.

### Supported Roles

- 👨‍💻 Job Seeker
- 🏢 Recruiter
- 🛡️ Admin

### Security Features

- JWT Authentication
- Password Hashing using bcrypt
- Protected Routes
- Role-Based Authorization
- Helmet Security Headers
- CORS Configuration
- Rate Limiting
- MongoDB Sanitization
- Environment Variables
- Secure API Access
